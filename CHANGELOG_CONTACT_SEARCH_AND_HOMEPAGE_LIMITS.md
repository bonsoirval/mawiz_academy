# Contact messages, Google Maps, and public discovery updates

- Added a public Contact form with name, email, subject, and message fields. Messages are validated and stored in the database.
- Added Admin > Contact Messages inbox with status updates (new, read, replied, archived).
- Contact page displays sample location, map, directions, phone, email, and social links when real values are not configured. Replace all sample values before production. Admin can configure contact values in Settings.
- Added admin settings for homepage program and course limits (0–50 each). The home page now shows separate program and course sections respecting those limits.
- Added public search on the Programs & Courses page, filtering both published programs and published courses.
- Existing global search remains unchanged.
