# Learning Path staged progression

- Replaced empty rectangles with four functional Learning Path stages: Hard Skills, Soft Skills, Work Simulation and Career Path.
- Hard Skills displays aggregate progress across published Hard Skills courses and links to continue or review them.
- Soft Skills unlocks only when all published Hard Skills courses are complete.
- Work Simulation unlocks only when all published Soft Skills courses are complete and provides Start/Continue/Review based on simulation attempts.
- Career Path unlocks after the required skill stages and published simulations have been attempted.
- Entrepreneurship and Job & Freelance are mutually exclusive; once selected, the choice cannot be changed through the learner interface.
- Added separate starter content pages for the two career directions.
- Removed the former requirement to select a career path before accessing courses, so learners can complete earlier stages first.
- Added responsive four-column layout, progress bars, lock states and left-to-right arrows.
