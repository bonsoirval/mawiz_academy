# Career Path Content-Only Management

- Career Path tab now opens the existing `/admin/career-path-content` management page directly.
- Career Path is exclusively managed through text resources, video resources, and flashcard resources assigned to Entrepreneurship or Job & Freelance.
- Removed the separate Career Path course/module/lesson/quiz/assignment management view from the course management workspace.
- Direct visits to `/admin/courses?stage=career_path` redirect to the canonical Career Path Content manager.
- Removed the obsolete back link to Career Path courses.
- Existing data is retained; this change does not delete any legacy Career Path course records.
