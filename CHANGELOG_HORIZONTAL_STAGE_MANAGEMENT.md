# Horizontal stage management navigation

- Added full-width horizontal navigation for Hard Skills, Soft Skills, Work Simulation, and Career Path.
- Hard Skills and Soft Skills reuse the existing course management interface, filtered by stage.
- Work Simulation remains on the horizontal tab and reuses the existing simulation authoring and publication interface.
- Removed the separate Projects and Simulations entries from the administrator left sidebar; the horizontal management tabs are the entry points for those workflows.
- Career Path now has its own course stage with course, module, lesson, quiz-question, and assignment authoring and publishing controls.
- Tabs are responsive and the selected tab is highlighted. Existing route-level permission checks and form actions remain in place.
