# Simulation program access and Career Path resources

- Learners only see published simulations linked to their enrolled course, a track attached to that enrolled course, or a module/lesson belonging to an enrolled course.
- Simulations without learning links are hidden from learners until linked.
- Simulation detail routes enforce the same access rule to prevent direct-URL access across programs.
- Career Path content management supports Entrepreneurship and Job & Freelance resources with text, video, and flashcards (one `Front | Back` pair per line).
- Resources are drafts by default and are visible only to learners who selected that path after the career-path stage unlocks.
- Added admin create/edit/publish/delete workflows and a learner-facing resource view.
