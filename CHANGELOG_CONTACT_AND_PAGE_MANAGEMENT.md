# Contact page and Page Management update

- Added a public `/contact` page with address/location, Google Maps embed or location link, directions, phone/email, WhatsApp, Telegram, Facebook, Instagram, LinkedIn and X links.
- Added admin Settings fields for contact details, map URLs, messaging links and social URLs.
- Added Contact to the CMS seed list, public navigation and sitemap.
- Reworked Page Management into a table with page title, URL, publish status, last-updated date and a Manage action.
- Manage opens a modal editor for title, slug, content and publish status. A separate Add page modal creates pages. Core pages are protected from deletion; admins can unpublish them instead.
