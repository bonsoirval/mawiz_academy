# Changelog — Collapsible left navigation

- Added a persistent desktop sidebar toggle in the authenticated application header.
- Collapsed desktop navigation reduces to an icon rail; expanding restores all labels and profile details.
- The selected desktop collapsed/expanded state is saved in browser local storage.
- On mobile and tablet widths, the same control opens and closes the navigation drawer, with outside-click dismissal.
- Added accessible toggle labels, expanded state, keyboard focus styling, and navigation tooltips.
- Implemented the behavior in the external application JavaScript so it works with the application's Content Security Policy.
